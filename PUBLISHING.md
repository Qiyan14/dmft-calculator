# Updating the website

GitHub Pages serves `docs/` on the main branch at https://qiyan14.github.io/dmft-calculator/.

1. Edit `app/app.R` and test locally with Shiny.
2. Run `Rscript tests/test_selected_model.R app/app.R analysis/04_Export_DMFT_Equation_Age_BMI.R` from the repository root. These are synthetic implementation checks, not study validation.
3. Run `source("update_app_source.R")` to copy the app into `docs/app.json` and update the cache version in `docs/index.html`.
4. Commit and push the source and generated files. Wait for the Pages workflow to finish.

For new runtime dependencies or a new Shinylive version, use `build.R`; then restore the versioned app request in `docs/index.html` and run `update_app_source.R`.

## Age/BMI model status

The study now uses numeric age and BMI with exhaustive single-marker and pair searches and beam search from size three. The previous age/sex model is not bundled. The selected-model calculator requires `dmft_age_bmi_model.csv` generated by the revised study scripts; it does not calculate a study risk until a valid new export is loaded. The user may upload this CSV in the browser. Do not substitute the old coefficients or relabel their performance as age/BMI results.

After the study rerun, a new verified CSV can be bundled deliberately. First check the export against the fitted model and update the reported cohort and performance from the corresponding workbook. The current loader checks configuration and search metadata.

The desktop app `analysis/06_Shiny_DMFT_Age_BMI.R` automatically loads `dmft_age_bmi_model.csv` from its working directory when available. Otherwise it uses the same upload flow as the browser.
